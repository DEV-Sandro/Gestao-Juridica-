Como gerar um documento em 6 passos

  1. 1 Faça upload de um documento modelo em .docx (Word).
  2. 2 No texto do modelo, escreva variáveis entre chaves: {cliente_nome}, {cliente_cpf}…
  3. 3 Salve o modelo. O sistema detecta as variáveis automaticamente.
  4. 4 Escolha o cliente e dê um nome ao documento.
  5. 5 O sistema substitui cada variável pelos dados do cliente cadastrado.
  6. 6 Baixe o documento preenchido, pronto para revisar e assinar.

info Use chaves simples { } — não duplas. Variáveis não reconhecidas saem com uma linha em branco para preencher à mão.
